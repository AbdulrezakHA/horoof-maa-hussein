# 📚 مجموعات الأسئلة (Presets)

كل ملف `.tsv` في هذا المجلد = مجموعة أسئلة واحدة، **واسم الملف هو اسم المجموعة**.
اللعبة تقرأ هذا المجلد تلقائياً — لا حاجة لأي إعداد.

---

## الأعمدة

| # | العمود | مطلوب | الشرح |
|---|--------|:-----:|-------|
| ١ | سؤال | ✅ | نص السؤال كما سيظهر على الشاشة |
| ٢ | جواب | ✅ | الجواب المختصر (كلمة أو كلمتان) |
| ٣ | حرف | — | اتركه فارغاً ليعمل **تلقائياً**. املأه فقط لتجاوز الاستنتاج |
| ٤ | نقاط | — | محفوظ للمستقبل (غير مستخدم في اللعب حالياً) |
| ٥ | ثواني | — | محفوظ للمستقبل |
| ٦ | تلميح | — | محفوظ للمستقبل |
| ٧ | فئة | — | محفوظ للمستقبل |

الفاصل بين الأعمدة هو **Tab** (وليس فاصلة). احفظ الملف بترميز **UTF-8**.

---

## كيف يُستنتج الحرف تلقائياً

1. يُنزع التشكيل والتطويل: `مُحَمَّد` ← `محمد`
2. تُنزع بادئة التعريف وأشباهها: `ال`, `وال`, `بال`, `كال`, `فال`, `لل`
   - `الكرة` ← `كرة` ← **ك**
   - `المشتري` ← `مشتري` ← **م**
3. تُطبَّع الهمزات والألفات: `أ إ آ ء` ← **ا**، `ؤ` ← **و**، `ئ ى` ← **ي**، `ة` ← **ه**
4. أول حرف يبقى هو حرف السؤال.

### متى تكتب الحرف يدوياً؟

- أسماء أجنبية تبدأ بـ «ال» وليست معرّفة: `المانيا` (الاستنتاج سيعطي **م**، والصحيح **ا**).
- أسماء أعجمية بحروف غير عربية.
- أي حالة ترى فيها أن الاستنتاج أخطأ.

---

## كيف تُنشئ مجموعة؟

الطريقة الأسهل: من صفحة **`/presets`** داخل اللعبة ← «➕ جديدة» ← «📋 لصق من جدول» ←
الصق عمودين من Google Sheets أو Excel ← «🔍 تحقّق» ← «✅ اعتماد» ← «💾 حفظ».

أو أنشئ ملفاً هنا مباشرة بهذا الشكل:

```
سؤال	جواب	حرف
ما عاصمة فرنسا؟	باريس
من كتب المقدمة؟	ابن خلدون
كم عدد أيام الأسبوع؟	سبعة
```

## مشاركة المجموعات

- **تصدير**: زر «⬇ تصدير» في صفحة `/presets` ينزّل الملف — أرسله لمن تريد.
- **استيراد**: «⬆ استيراد» ← الصق أو ألصق محتوى الملف ← يُنشأ كمجموعة جديدة.

## قواعد مهمة

- **كل جواب يجب أن يبدأ بحرفه** — هذه هي فكرة اللعبة.
- لا تكرّر السؤال نفسه داخل المجموعة (التكرار يُتجاهل تلقائياً مع تنبيه).
- ١٠ أسئلة على الأقل لكل حرف = مباراة مريحة. الأقل من ذلك يفرغ السؤال بسرعة.
- عند اختيار عدة مجموعات في إعدادات الحكم، تُسحب الأسئلة عشوائياً من كل المفعّل،
  والتكرار بين المجموعات يُمنع تلقائياً.
