# حروف مع حسين — لعبة حروف تنافسية بشاشتين

> **لست مبرمجاً؟ ابدأ من هنا:** [`دليل-الاستخدام.md`](دليل-الاستخدام.md)

## التحميل على جهاز جديد (بدون حساب GitHub)

1. افتح **https://github.com/AbdulrezakHA/horoof-maa-hussein** ← زر **Code** الأخضر ← **Download ZIP**
   (أو الرابط المباشر: https://github.com/AbdulrezakHA/horoof-maa-hussein/archive/refs/heads/main.zip).
2. انقر بزر الفأرة الأيمن على الملف ← **Extract All** (فكّ الضغط) — لا تشغّل اللعبة من داخل الـZIP.
3. شغّل **`install.bat`** مرة واحدة (يطلب صلاحية المدير، ويحمّل Node تلقائياً إن لم يكن موجوداً — يحتاج إنترنت).
   إن ظهرت رسالة «Windows protected your PC» اضغط **More info ← Run anyway**.
4. بعدها شغّل اللعبة دائماً من **`ابدأ-اللعبة.bat`** (أو اختصار سطح المكتب).

لعبة مبنية على فكرة «الخليّة»: شبكة من 25 خلية سداسية، كل خلية تحمل حرفاً،
وسؤالاً يبدأ بذلك الحرف. فريقان يتنافسان على توصيل **طرفي لونهم** عبر الخلايا التي يملكونها.

| الشاشة الكبيرة (`/screen`) | لوحة الحكم (`/referee`) | أجراس اللاعبين (`/buzzer`) |
| --- | --- | --- |
| تُعرض على جهاز العرض أو التلفاز | تعمل على جوال الحكم | جوال لكل فريق (اختياري) |
| تعرض اللوحة، الحرف المختار، السؤال، المؤقّت، والنقاط | **لا يعرض الجواب أبداً** على الشاشة الكبيرة | زر واحد كبير للضغط عند معرفة الإجابة |
| لا يمكنها إرسال أي أمر | كل التحكم يصدر منها | أول ضغطة فقط تُحتسب |

## نظام التصميم

كل الشاشات (التلفاز، الحكم، جوال اللاعب، صفحات الإدارة) مبنية من **مكتبة واحدة**:

- `DESIGN.md` — القواعد (ملف واحد يقرؤه كل من يعدّل الواجهة).
- `/design` — صفحة تعرض كل عنصر وكل حركة وهي تعمل (افتحها أثناء تشغيل اللعبة).
- `public/css/ds.css` و`shared/ds-theme.js` و`public/icons.svg` و`public/js/ds.js` — المكتبة نفسها.
- **لا إيموجي ولا ألوان مكتوبة ولا خطوط** داخل ملفات الألعاب: كل شيء يأتي من المكتبة.

الفحص التلقائي لقواعد التصميم:

```
npm run ds:check
```

وبعد تعديل ألوان الثيمات في `shared/ds-theme.js`:

```
npm run ds:theme
```

الثيمات الخمسة (سهرة الألعاب، ليلي، كلاسيكي، رمضاني، زاهي) يبدّلها الحكم من «الإعدادات وتخصيص الألوان»،
فتتغيّر كل الشاشات معاً.

## ما تم تنفيذه

- **جهازان مرتبطان** عبر WebSocket في الوقت الحقيقي (الخادم هو المصدر الوحيد للحقيقة).
- **الحكم يرى الجواب، اللاعبون لا يرون الجواب** — فصل كامل على مستوى الخادم: الشاشة تستقبل الحالة نفسها لكن الحقل `question` يبقى بلا عرض عندها.
- **الحرف يُختار عشوائياً** أو يدوياً، والسؤال يظهر للحكم أولاً ثم يضغط «عرض على الشاشة».
- **اللوحة تُخلط عشوائياً** (Fisher–Yates) عند إنشاء كل غرفة وعند كل «إعادة جولة» — نفس الحروف، مواقع مختلفة كل مرة.
- **«سؤال آخر»** يعطي سؤالاً مختلفاً لنفس الحرف (مع عدم تكرار الأسئلة حتى تُستهلك كلها).
- **المؤقّت التلقائي**: أول ضغطة على الجرس تشغّل مؤقّت اللاعب الأول (**٣ ثوانٍ افتراضياً**)، وعند انتهائه يبدأ مؤقّت
  اللاعب الثاني **تلقائياً** (**١٠ ثوانٍ افتراضياً**؛ والمدّتان يضبطهما الحكم: ٣–١٢٠ ثانية). المؤقّت يظهر على الشاشة **وعلى
  جوالَي اللاعبين**، ولونه ونبضته من **لون الفريق صاحب الدور** كما اختاره الحكم. وتُظهر لافتة الشاشة **الوضع الحالي دائماً**: اسم صاحب الدور مع **عدّاد الثواني
  الحيّ**، وتتبدّل من «ضغط أولاً!» إلى «الآن دور الفريق الآخر» عند انتقال الدور.
- **تعديل الإعدادات**: أسماء الفريقين، ألوانهما، وحروف اللوحة كلها — من جوال الحكم.
- **أجراس الجوال**: جوالان يعملان كجرس — أول ضغطة تفوز، وتُفتح الأجراس **تلقائياً** عند عرض السؤال،
  ويشغّل المؤقّت بنفسه (٣ ث للاعب الأول ثم ١٠ ث للاعب الثاني). كل جوال يلبس **لون فريقه** ويتبعه لحظياً،
  وكل شيء يُصفَّر تلقائياً عند تغيير السؤال — بلا أي تدخّل من الحكم.
- **مؤثرات صوتية (SFX)**: صوت لكل حدث (كشف، فتح، رنّة، عدّ الثواني، نقطة، فوز...) مع **زر كتم
  مستقل لكل جهاز** (الشاشة، لوحة الحكم، جوال كل فريق) محفوظ في المتصفح.
- **تصحيح الأخطاء**: إعادة اختيار خلية مملوكة، نقلها لفريق آخر، أو إزالتها بالكامل.
- **كشف الفوز تلقائياً** عبر خوارزمية ربط الجيران (BFS) على الشبكة السداسية + قصاصات احتفالية.
- **بنية صفر الاعتمادات**: لا `npm install`، Node 18+ فقط.
- **مجموعات الأسئلة (Presets)**: كل مجموعة ملف `presets/*.tsv` باسمها، وبها **السؤال والجواب فقط** —
  واللعبة تستنتج **حرف السؤال تلقائياً** من أول حرف في الجواب (متجاهلة التشكيل و«ال» التعريف وأشكال الهمزة).
  يمكن اختيار **أكثر من مجموعة** في الوقت نفسه (تُسحب الأسئلة عشوائياً من كل المفعّل بلا تكرار)،
  وهناك صفحة **`/presets`** للتعديل والمعاينة والتحقق، مع **لصق مباشر من Google Sheets/Excel**،
  وتصدير/استيراد لمشاركة المجموعات مع أي لاعب آخر.

## التشغيل على جهازك

### الطريقة الأسهل (موصى بها)

**اضغط مرتين على `ابدأ-اللعبة.bat`** — يشغّل الخادم ويفتح شاشة اللعبة تلقائياً.

> الضغط مرة أخرى **لا يشغّل نسخة ثانية**: إن كانت اللعبة تعمل بالفعل فسيكتفي بفتح الشاشة،
> حتى لا ينتقل الخادم الجديد إلى منفذ آخر وتصبح رموز QR موجّهة للخادم القديم (٤٠٤).

### الطريقة اليدوية

```bash
cd "D:\حروف مع حسين صديلي"
node server/index.js
```

ثم افتح **<http://localhost:3000>** — الصفحة الرئيسية تعرض روابط الشاشة والحكم ورمز QR.

### ربط الجوال

**الطريقة الأسهل:** افتح `/screen` على التلفاز → تظهر **قائمة بداية** فيها **ثلاثة رموز QR**:
رمز الحكم، ورمز لكل فريق (جرس اللاعبين). امسح رمز الحكم بكاميرا جوالك لفتح لوحة التحكم،
وامسح رمز كل فريق بجوال ذلك الفريق وضعه على الطاولة. القائمة **لا تختفي من تلقاء نفسها**؛
اضغط «▶ابدأ اللعب» من جوال الحكم (بطاقة «الشاشة الكبيرة») عندما تكون جاهزاً،
ومن نفس البطاقة تعيد إظهار الرموز أو تكتم صوت التلفاز — التلفاز للعرض فقط ولا يحتاج فأرة.

(الطريقة اليدوية: تأكّد أن الكمبيوتر والجوال على نفس شبكة الواي-فاي، والخادم يطبع عنوان شبكتك تلقائياً — `http://192.168.100.2:3000` — ثم افتح `http://192.168.100.2:3000/referee` على الجوال.)

**للتجربة بدون جوال:** افتح `http://localhost:3000/referee` في تبويب آخر — نفس لوحة التحكم. (أو اضغط رابط «تجربة سريعة» داخل قائمة البداية.)

### إذا لم يفتح الجوال الرابط

الخادم الآن يستمع لجميع أجهزة الشبكة المحلية تلقائياً. عند أول تشغيل قد تعرض Windows نافذة تسأل عن السماح لـ **Node.js** بالوصول للشبكات؛ اختر **Allow access** مع تفعيل **Private networks**. إذا سبق أن رفضتها، جدار حماية Windows يمنع الاتصال الوارد. افتح PowerShell **كمسؤول** ونفّذ:

```powershell
netsh advfirewall firewall add rule name="HiveGame" dir=in action=allow protocol=TCP localport=3000
```

أو من **Windows Defender Firewall → Allow an app** أضف `node.exe`.

### الاتصال من خارج الشبكة

لا يمكن للهاتف الوصول إلى خادم يعمل على كمبيوتر منزلي من الإنترنت مباشرةً؛ يلزم عنوان عام آمن عبر استضافة أو نفق HTTPS. بعد إنشاء عنوان عام (مثلاً عبر Cloudflare Tunnel) شغّل الخادم مع عنوانه:

```powershell
node server/index.js --public-url https://your-game.example.com
```

سيظهر خيار «اتصال عبر الإنترنت» في شاشة البداية. كل هاتف حكم يحتاج إلى إدخال رمز الأمان ذي الستة أرقام الظاهر على شاشة اللعبة قبل أن يستطيع التحكم بها. استخدم دائماً رابط HTTPS ولا تشارك الرمز مع غير الحكم.

### التركيب على جهاز آخر (حزمة جاهزة)

الحزمة `Horoof-Maa-Hussein-Setup-v1.0.0.zip` (≈٣٧ ميجا) تحتوي اللعبة كاملة **+ مفسّر Node محمول**، فلا حاجة لتثبيت شيء على الجهاز الآخر:

1. فكّ ضغط الحزمة في أي مكان.
2. انقر بزر الفأرة الأيمن على `install.bat` ← «تشغيل كمدير للنظام».
3. ستظهر أيقونة **«حروف مع حسين»** على سطح المكتب وفي قائمة ابدأ — من الآن انقر عليها فقط.

ما يفعله `install.bat` مرة واحدة:

| الخطوة | التفصيل |
|---|---|
| مفسّر Node | يستخدم `runtime\node.exe` المرفق، وإن لم يوجد يجلبه من nodejs.org تلقائياً |
| جدار الحماية | يضيف قاعدة دخول TCP **3000** للشبكات الخاصة (اسمها `HoroofMaaHussein`) |
| الاختصارات | سطح المكتب + قائمة ابدأ |
| العناوين | يطبع روابط الجهاز والموبايل في نهاية التركيب |

> لا يحتاج اللعب إلى إنترنت: شبكة محلية فقط. ملف `README-FIRST.txt` داخل الحزمة يشرح كل ذلك بالعربية.
> ولو تغيّر المنفذ لاحقاً، عدّل `PORT` في `ابدأ-اللعبة.bat` وافتح المنفذ الجديد في الجدار الناري.

**إعادة بناء الحزمة** (بعد أي تعديل على اللعبة):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-setup.ps1
```

السكربت يجلِب Node إن لم يكن موجوداً في `runtime\`، يبني الـzip في `D:\_dist\`، ثم **يفكّ ضغطه ويشغّله فعلياً** في مجلد مؤقت ويتحقق من `/api/health` و`/screen` و`/presets` قبل أن يعتبره ناجحاً.

### خيارات التشغيل

```bash
node server/index.js --port 8080     # منفذ مختلف
node server/index.js --host 127.0.0.1 # الوصول من الجهاز نفسه فقط
```

> **مهم:** إذا كان المنفذ المطلوب مشغولاً (نسخة قديمة من الخادم ما زالت تعمل)،
> ينتقل الخادم تلقائياً للمنفذ التالي (`3001`, `3002`, …) ويطبع المنفذ الفعلي في الشعار.
> `/api/network` يعيد **المنفذ الفعلي**، ورموز QR تُبنى على المنفذ الذي فتحت منه الصفحة —
> لذلك يجب أن تكون الصفحات ورموز QR كلها من **نفس النسخة**.
> **لا تشغّل نسختين معاً**: أوقف القديمة (أغلق نافذتها) قبل تشغيل الجديدة، وإلا
> قد تفتح رموز QR على الخادم القديم فترجع **404**.
> للتأكد: افتح `http://localhost:3000/api/network` وشاهد قيمة `port`.

## طريقة اللعب

| الخطوة | على جوال الحكم | على الشاشة |
| --- | --- | --- |
| ١ | اضغط «حرف عشوائي» أو اضغط حرفاً في اللوحة المصغّرة | الحرف المحدد يتوهّج بإطار ذهبي |
| ٢ | السؤال والجواب يظهران لك فقط | المنطقة فارغة تماماً (بلا أي نص) |
| ٣ | «عرض على الشاشة» | يظهر السؤال نصاً كبيراً + تُفتح الأجراس تلقائياً |
| ٤ | إن كان السؤال غير مناسب: «سؤال آخر» | يُمسح السؤال القديم ويُصفَّر كل شيء تلقائياً |
| ٥ | أول ضغطة على الجرس: «الفريق الأول — ٣ ث» | لافتة «ضغط أولاً!» + **عدّاد حيّ** بلون الفريق الأول |
| ٦ | «الفريق الثاني» — يبدأ تلقائياً بعد انتهاء الأول | تتبدّل اللافتة إلى «الآن دور الفريق الآخر» + عدّاد ١٠ ث بلون الفريق الثاني |
| ٧ | لا جواب: يبقى كل شيء حتى تختار سؤالاً آخر | ⋯ |
| ٨ | «نقطة للفريق الأول» | تلوّن الخلية + زيادة النقاط + لافتة «نقطة محسوبة!» |
| ٩ | بالخطأ: اضغط الخلية ثم الفريق الآخر أو «إزالة» | تتحدّث فوراً |

**الفوز**: يربط **الفريق الأول** (لونه الافتراضي بنفسجي `#6965ae`) طرفيه (أعلى ↔ أسفل)،
و**الفريق الثاني** (لونه الافتراضي سماوي `#4b9cbf`) (يمين ↔ يسار).
اللاعبان يتقاطعان في الوسط، فكل فريق يحاول منع الآخر.

## أجراس الجوال (وضع «الأوتوماتيك»)

بدل ما يرفع اللاعب يده، يضع كل فريق جوالاً على الطاولة مفتوحاً على صفحة الجرس.

1. **من قائمة البداية على الشاشة**: امسح رمز الفريق الأول بجواله، ورمز الفريق الثاني بالآخر.
   (أو من جوال الحكم: القسم «أجراس اللاعبين» فيه رمزا QR للفريقين.)
2. **من جوال الحكم → أجراس اللاعبين**: الأجراس **مفعّلة افتراضياً**؛ اضبط **مدّة اللاعب الأول** (٣ ث افتراضياً)
   و**مدّة اللاعب الثاني** (١٠ ث افتراضياً). (يمكن إيقافها كلياً بزر «تشغيل أجراس اللاعبين».)
3. يضغط الحكم «عرض على الشاشة» → يظهر على الشاشة السؤال وتُفتح الأجراس **تلقائياً**
   (لا حاجة لفتحها قبل كل سؤال).
4. أول ضغطة تفوز: تظهر على الشاشة بلون الفريق الفائز **«ضغط أولاً!»** مع **عدّاد الثواني الحيّ**، وجواله يتوهّج بلونه
   مع صوت كل ثانية، بينما جوال الخصم باهت بلا صوت. باقي الضغطات تُتجاهل.
5. عند انتهاء وقت اللاعب الأول يبدأ وقت اللاعب الثاني **تلقائياً** بنفس التأثيرات، وتتبدّل لافتة الشاشة
   إلى **«الآن دور الفريق الآخر»** مع عدّادها (١٠ ث افتراضياً) وبلون صاحب الدور — فتظل اللافتة
   تعرض **الوضع الحالي دائماً** لا اسم من ضغط أولاً فقط.
6. **إعادة الأجراس**: تلقائياً عند اختيار حرف آخر (يُمسح السؤال القديم من الشاشة) — أو يدوياً
   بزر «↺ إعادة الأجراس».
7. **«صحيح للفريق»**: جوال الفريق الفائز يحتفل (قصاصات + وميض + «إجابة صحيحة!»)، وجوال الخصم
   يخبره أن الطرف الآخر أخذ النقطة، وتظهر على الشاشة لافتة «نقطة محسوبة!».
8. **لو ما تبغى تكشف السؤال**: اضغط «افتح الإجابة الآن» → تُفتح الأجراس بلا كشف نص السؤال.

> **ملاحظات**: لون جوال كل فريق يتبع **لون فريقه** في الإعدادات ويتبدّل لحظياً مع قوالب الألوان
> في لوحة الحكم. ولكل جهاز **زر كتم أصوات** مستقل (/) محفوظ في المتصفح.

## التخصيص

### تغيير حروف اللوحة

عدّل `data/board.json` ثم أعد تشغيل الخادم:

```json
{ "id": "r0c0", "r": 0, "c": 0, "letter": "م" }
```

أو من **جوال الحكم**: الإعدادات ← «تعديل حروف اللوحة» (يُطبَّق فوراً بلا إعادة تشغيل).

> **قاعدة الحروف:** الشبكة تعرض **الحروف الأساسية الـ٢٨ فقط** (ا ب ت ث ج ح خ د ذ ر ز س ش ص ض ط ظ ع غ ف ق ك ل م ن ه و ي)
> ولا يتكرّر أي حرف مرّتين. ولأن الشبكة ٢٥ خلية والعدد ٢٨، **تُسحب ٢٥ حرفاً بالقرعة في كل جولة** (تُستبعد ٣ حروف) ثم تُسحب غيرها في الجولة التالية، فتدور كل الحروف ولا يبقى حرف خارج الشبكة دائماً. أي حرف آخر (أ إ آ ء ؤ ئ ى ة …) يُردّ تلقائياً إلى أصله:
> أ/إ/آ/ء ← ا، ؤ ← و، ئ/ى ← ي، ة ← ه. المحرّك يطبّق هذا عند الإقلاع وعند كل جولة جديدة وعند تغيير أي خلية،
> وفي قائمة اختيار الحرف تكون الحروف المستخدمة في خلايا أخرى **معطّلة** حتى لا يتكرّر حرف.

### تغيير الألوان والأسماء

من الإعدادات في الجوال، أو من `data/board.json`:

> المؤقّت على الشاشة يعرض **لون** الفريق صاحب الدور فقط (بلا اسم)، بينما لوحة الحكم
> تعرض الاسم الذي تكتبه. الأسماء الافتراضية: «الفريق الأول» و«الفريق الثاني».

```json
"teams": {
  "a": { "name": "الفريق الأول", "color": "#6965ae", "goals": [["top"], ["bottom"]] },
  "b": { "name": "الفريق الثاني", "color": "#4b9cbf", "goals": [["left"], ["right"]] }
}
```

### مجموعات الأسئلة

**لا تعدّل JSON.** كل مجموعة = ملف `presets/<الاسم>.tsv` فيه عمودان فقط: **سؤال** و**جواب**،
واللعبة تستنتج حرف السؤال من أول حرف في الجواب تلقائياً.

**الطريقة الأسهل:**
1. افتح `/presets` (أو: جوال الحكم ← الإعدادات ← مجموعات الأسئلة ← «إدارة وتعديل المجموعات»).
2. «جديدة» ← اكتب الاسم.
3. «لصق من جدول» ← انسخ عمودين من Google Sheets / Excel والصقهما ← «تحقّق» ← «اعتماد».
4. «حفظ».

**الاستنتاج التلقائي** يتجاهل التشكيل و«ال» التعريف ويوحّد الهمزات:

| الجواب | الحرف |
|---|---|
| `الكرة` | **ك** (نُزعت «ال») |
| `أموكسيسيلين` | **ا** |
| `مُحَمَّد` | **م** |
| `طوكيو` | **ط** |

لو أخطأ الاستنتاج (مثل `المانيا`) اختر الحرف يدوياً من قائمة العمود الثالث — يُحفظ التخصيص.

**أكثر من مجموعة في اللعبة:** من الإعدادات علّم كل المجموعات التي تريدها ← تُسحب الأسئلة عشوائياً
من كل المفعّل بلا تكرار. القائمة الفارغة = كل المجموعات.

**مشاركة المجموعات:** «تصدير» ينزّل الملف، و«استيراد» يقبل ملفاً أو نصاً ملصوقاً.
التفاصيل الكاملة في `presets/README.md`.

### تغيير أسئلة الحرف (الطريقة القديمة عبر ملفات .md)

عدّل ملفات `.md` ثم:

```bash
node scripts/build-questions.mjs
```

يقبل المحوّل أي صيغة: `### **[ ح ]**` ثم `1. **الجواب:** نص السؤال`.
يحذف تلقائياً عبارة «يبدأ بـ (ح)؟» من نهاية السؤال.

## الاختبارات

```bash
node server/index.js --port 3111      # في نافذة منفصلة
node scripts/test-game.mjs 3111
```
يغطي: تقديم كل الصفحات (`/`, `/screen`, `/referee`, `/buzzer`) وملفات CSS/JS، المزامنة بين الجهازين،
منع الشاشة من التعديل، إظهار/إخفاء السؤال، تغيير السؤال، نقل الملكية، الإزالة، المؤقّت،
كشف الفوز للطرفين، إعادة الاتصال، وعزل الغرف، **وخلط اللوحة العشوائي**، و**أجراس اللاعبين**:
الفتح التلقائي عند كشف السؤال، أول ضغطة تفوز، تجاهل الضغطات اللاحقة، حجب نص الإجابة عن الجوال،
المؤقّت التلقائي (مدّة افتراضية ٣ ث للأول و١٠ ث للثاني) وانتقال الدور للاعب الثاني، إعلان النقطة (verdict)، والتصفير التلقائي عند تغيير السؤال، **ومجموعات الأسئلة**:
ترحيل البنك القديم، استنتاج الحرف تلقائياً (نزع «ال» والتشكيل)، لصق الجداول، إنشاء/حفظ/قراءة/حذف مجموعة،
تخصيص الحرف يدوياً، تفعيل مجموعة واحدة فيتغيّر البنك فوراً، التصدير، وتنظيف الاختيار بعد الحذف.
وأخيراً **سلامة الحروف ودورانها**: كل خلايا الشبكة من الحروف الأساسية الـ٢٨ بلا أي تكرار، وتُسحب ٢٥ حرفاً بالقرعة
في كل جولة (٣ حروف تُستبعد وتتغيّر الجولة التالية، فلا حروف محرومة دائماً)، وتطبيع الحروف عند الإقلاع وعند كل جولة
وعند تغيير حرف من لوحة الحكم (ؤ ← و، أ ← ا، ى/ئ ← ي، ة ← ه).

## النشر لاحقاً (Vercel / VPS)

المشروع **ليس** جاهزاً للنشر على Vercel كـ serverless لأن Vercel لا يدعم اتصالات WebSocket دائمة.
عندك مساران:

### المسار ١ — VPS (موصى به، أبسط وأرخص)

```bash
# على الخادم
git clone <repo> && cd hive-game && node server/index.js
```

خلف Nginx مع WebSocket:

```nginx
server {
  listen 443 ssl;
  server_name hive.example.com;
  location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
  }
}
```

ثم شغّله بـ `pm2 start server/index.js --name hive`.

### المسار ٢ — Vercel للواجهة فقط + خدمة WebSocket مُدارة

- انشر مجلد `public/` + `shared/` على Vercel كملفات ثابتة.
- استخدم خدمة WebSocket مُدارة (مثل Ably أو Pusher) بدل الخادم المحلي.
- المطلوب: تغيير `public/js/transport.js` فقط — طبقة النقل معزولة عن بقية الشيفرة،
  فالسيرفر الجديد يجب أن يرسل نفس رسائل `{t:"state"}` ويستقبل `{t:"action"}`.

### المسار ٣ — أبقِه محلياً (الأسهل للتصوير)

شغّل الخادم على الكمبيوتر، واجعل الجوال يتصل عبر الشبكة المحلية.
لا حاجة لأي استضافة أو حساب أو إنترنت أثناء التصوير.

## ملاحظات

- **اللعبة تعمل بدون إنترنت** (الخطوط من Google Fonts تُحمَّل اختيارياً، وتوجد بدائل محلية).
- الحالة في **ذاكرة الخادم**: إذا أُغلق الخادم أثناء التصوير فستُمسح الجولة — لا بأس.
  للاستخدام الطويل شغّل `pm2` أو استخدم `screen`/`tmux`.
- الشاشات المتعددة: افتح `/screen` على أكثر من جهاز، كلها تتزامن.
- الغرف: `http://localhost:3000/referee?room=abc` و `.../screen?room=abc` لعزل أكثر من جولة.
- لمعاينة واجهة الجوال على شاشة كبيرة: افتح لوحة الحكم من متصفح الكمبيوتر وصغّر عرض النافذة، أو استعمل أدوات المطوّر.
